# L6 Scrape Fixtures

Use this folder only for tiny synthetic or sanitized fixtures needed by tests.

Good fixture examples:

- a small official-product HTML sample;
- a blocked/CAPTCHA-like HTML sample that should classify as blocked;
- a short extracted-text sample with a visible contract clause;
- a minimal registry CSV row.

Do not store full live crawls, large PDFs, raw institution dumps, or private/gated material here.
